### ISO 9141-2

https://www.iso.org/standard/16738.html
https://github.com/AutotronicCommunity/Honda_Keihin_KLine_Protocol
Use a UART interface with an automotive K-line transceiver supporting 10400 baud, 8N1, no flow control, and BREAK/line-low control.

```text
1. Release K-line HIGH/idle, wait 6 s, clear RX buffer.
2. Drive K-line LOW for 70 ms, release HIGH for 130 ms.
3. Clear wake/echo artifacts from RX with: FE 04 36 C8
4. Receive and validate:                 0E 04 36 B8
5. Wait 50 ms, send a table payload e.g. 25 05 71 D1 94
6. Receive: 05 25 71 D1 [32 bytes] CS (37 bytes total)
7. 200 ms polling if reading other pages
```

#### `05 LEN 71 PAGE DATA... CS`
`LEN` includes header/checksum, DATA starts at byte 4. Match the page and require `sum(packet) & 0xFF == 0`. To build a request, append `CS = (-sum([0x25, 0x05, 0x71, page])) & 0xFF`.

10400 baud and the 70/130 ms pulse, 6 s idle, 50 ms delay and 200 ms polling are prototype values, not proven timeouts. This uses Honda K-line framing.
